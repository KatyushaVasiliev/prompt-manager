# 프롬포트 관리 프로그램

터미널에서 재사용할 AI 프롬포트를 관리하는 Python 콘솔 프로그램입니다.

## 기능

- 프롬포트 추가 및 전체 목록 보기
- 카테고리별 조회와 키워드 검색
- 프롬포트 상세 보기
- 즐겨찾기 등록/해제 및 즐겨찾기 목록 보기
- 교육, 업무, 여행 카테고리의 기본 프롬포트 3개 제공

프로그램을 실행하는 동안 추가한 프롬포트와 즐겨찾기 상태는 유지되며, 종료하면 초기화됩니다.

## 데이터 구성

기본 데이터는 교육·업무·여행 카테고리의 예시 프롬포트 3개입니다. 별도의 파일이나 데이터베이스를 사용하지 않아 개인 프롬포트가 외부에 저장되지 않습니다.

## 실행 방법

Python 3.7 이상에서 다음 명령을 실행합니다.

```powershell
py -3 prompt_manager.py
```

메뉴 번호를 입력하여 기능을 선택합니다. 종료하려면 `0`을 입력합니다.
즐겨찾기는 메뉴 `6`에서 프롬포트 번호를 입력해 등록하거나 해제하고, 메뉴 `7`에서 모아 볼 수 있습니다.

## 테스트

기본 데이터, 카테고리, 즐겨찾기 목록, 상세 보기 동작은 다음 명령으로 확인할 수 있습니다.

```powershell
py -3 -m unittest discover -s tests
```

## 과제 요구사항 충족 현황

| 요구사항 | 구현 내용 |
| --- | --- |
| 콘솔 메뉴 | `1`~`7`, `0` 메뉴 번호로 기능 선택 |
| 프롬포트 관리 | 추가, 전체 목록, 카테고리 조회, 검색, 상세 보기 |
| 즐겨찾기 | 등록/해제와 즐겨찾기 목록 제공 |
| 실행 중 데이터 유지 | 메모리 목록을 공유해 종료 전까지 추가·즐겨찾기 상태 유지 |
| 기본 데이터 | 교육, 업무, 여행 프롬포트 3개 제공 |
| 코드 품질 | 각 기능을 독립 함수로 분리하고 자동 테스트 제공 |
| Git 이력 | 기능 단위 커밋 10개 이상과 브랜치 병합 이력 포함 |
